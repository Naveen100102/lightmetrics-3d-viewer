# LightMetrics viewer design system

Adapted from https://lightmetrics-ed.webflow.io/ and its public Webflow stylesheet, inspected October 8, 2026. Scope: theme the existing Three.js viewer; no migration of the original site's CMS, forms, marketing pages, or animation runtime.

- Headings: Aspekta 400, line-height 1–1.1, letter spacing -0.03em.
- Body: DM Sans 400, 16px / 1.5.
- Labels and actions: Geist Mono 400, uppercase.
- Surfaces: white, #ebebeb, #080808 and black.
- Text: #151515; secondary #757575; borders #c2c2c2.
- Brand accent: #961a86; pale accent #ffeef8.
- Desktop page margin: 40px. Adapted tablet/mobile margins: 24px/20px.
- Source responsive boundaries: 991px, 767px, 479px.
- Square outlined controls and monochrome active states; purple for toggled options and focus.
- Header uses the original white LightMetrics logo. Fonts and logo use the source site's public CDN assets.

The viewer layout and product content are specific to this app. Its 3D scene, reference comparison, rotation, panning, presets and GLB export are retained. This is a design-system adaptation, not a pixel-for-pixel homepage copy.
